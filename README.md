# akshittyagi777.github.io

[![Deploy to GitHub Pages](https://github.com/akshittyagi777/akshittyagi777.github.io/actions/workflows/deploy.yml/badge.svg?branch=main)](https://github.com/akshittyagi777/akshittyagi777.github.io/actions/workflows/deploy.yml)

Personal site, built with SvelteKit and deployed to GitHub Pages by the workflow
above. Live at [akshittyagi777.github.io](https://akshittyagi777.github.io).

The badge shows the status of the most recent deploy on `main` — green when the
latest build and deploy succeeded, red when it failed. Click it for the run logs.

## Local development

```bash
npm install
npm run dev      # dev server
npm run build    # production build into build/
```

Static assets in `static/` are copied to the site root, so `static/files/x.pdf`
is served at `/files/x.pdf`.
